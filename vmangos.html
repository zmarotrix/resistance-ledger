Is VMaNGOS a credible source?

Every number on this site was checked against VMaNGOS, an open-source World of Warcraft 1.12 server. For Classic raid mechanics there's no better public source. This page shows why, and where its few soft spots are.

The short answerBack to the main page
10-second version

Yes. It's the best source there is. Blizzard never released its server code, so every other source is a wiki summary, a guide or a forum memory. VMaNGOS takes its spell numbers straight from the 1.12 game files, and has spent years tuning its rules against vanilla packet captures, videos and tests on Blizzard's own WoW Classic. Where it has gaps, it marks them in the code.

I

What VMaNGOS is

VMaNGOS is a free, open-source server that runs the World of Warcraft 1.12 client. To run at all, it has to decide every hidden rule the real server used: how often spells miss, how resistance becomes a percentage, what each boss does and when.

Its README states accuracy as the goal, with any custom behaviour behind a config option. It also requires that "every piece of data must be marked with the patch in which it was added or changed". Its world database holds every patch from 1.2 to 1.12.1

The resistance code descends from Nostalrius, a 2015–2016 private server. You can tell because its comments are signed "NOSTALRIUS" and some are written in French.2

It's been tested against the real thing

When Blizzard launched WoW Classic in 2019, VMaNGOS's developers had a live reference to test against. The code is full of the results:

  • "Miss chance due to level difference is capped according to tests on classic." That one sets the 22% minimum hit chance. SpellCaster.cpp:830
  • "TEST RESULTS FROM CLASSIC WITH SNIFFED EXACT POSITIONS" Unit.cpp:6547
  • "More confirmation from classic sniffs" on Ouro boss_ouro.cpp:72
  • Database updates "based on classic sniffs" and "data from classic 1.13"

Comments mention packet captures over 440 times, and 70 database updates cite them. A sniff is a recording of exactly what Blizzard's server sent, so it's the ground truth for timers, targets and damage.

It has to be right to run

A wiki can say "5 per level" and "8 per level (believed)" on the same page, and nobody notices. A server can't. Every rule in VMaNGOS is played against by real raids, week after week, and a wrong number shows up as a boss that feels off.

The code it grew from ran large vanilla servers like Nostalrius and Light's Hope through full progression. Raiders there compared fights with their saved logs and videos of the original game, reported what felt wrong, and the fixes landed in the database. No wiki has had that many testers.

The project's rule is that "every piece of data must be marked with the patch in which it was added or changed". So it can tell you what Ragnaros did in patch 1.2 and in 1.12. Most sources can't.

IV

What makes it a good source

The spell numbers are Blizzard's. The spell table is a copy of the client's own spell file for each build, from 4222 (patch 1.2) up to 5875 (1.12.1). When this site says Wrath of Ragnaros does 1,000 fire damage, that number shipped on players' hard drives in 2006. We cross-checked the icons and spell names against a 1.12 client's files directly.

It's versioned by patch. Elemental Fire did 1,800–2,200 in patch 1.2 and 2,160–2,640 from 1.3. VMaNGOS keeps both. A wiki usually shows only one, without saying which patch.

It cites its evidence. Comments quote patch notes, packet captures and videos. One example: four DoTs resist at the full rate because "we have a video proof".

It has to be consistent. A wiki can say two contradictory things on one page, and this one does: 5 per level and "8 per level (believed)". Code has to pick one number and run it.

V

Its known limits

These are the places where VMaNGOS itself says it's less sure. None of them makes another source better. They're spots where nobody outside Blizzard has a certain answer.

The resistance formulas are reconstructed, not copied. Blizzard's server code isn't public, so the maths was rebuilt from a Blizzard-style table, developer posts and testing. It matches what players measure. It just can't be read line by line against the original.

One rule is openly a best guess. How often damage-over-time ticks get resisted is called "somewhat a guess". It's built on a Blizzard developer's post plus video evidence, which is more than any other source offers.

The partial-resist table was copied by hand from an image. A few rows don't add up to 100% (see the table). The blending between rows keeps the effect small.

Some hand corrections don't say where they came from. Flags like "unresistable" sit in a corrections table, often with no note. One script comment also disagrees with the database: the Nefarian script says Shadow Flame does "about 1000", while the client data says 3,938–5,062. This site uses the client data.

X

How to use VMaNGOS numbers

Quote as fact

  • Spell damage, ranges, buff values: client data.
  • Item stats.
  • Which patch changed what.
  • Hit and resistance formulas: the best answer available.

Quote with a note

  • The damage-over-time resist rule, which the code calls a guess.
  • "Unresistable" flags with no source in the corrections table.

Double-check

  • Script comments that disagree with the database. Trust the data.
  • Patches before 1.12, where fewer captures exist.
